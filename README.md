# Smart Reminder AI

An intelligent task and reminder application that helps users manage tasks, prioritize work, track productivity, and receive AI-powered completion predictions and recommendations.

## Tech Stack
* **Language**: Python
* **Database**: SQLite (introduced in Phase 2)
* **Data & Visualization**: Pandas, Matplotlib (introduced in Phase 5)
* **Machine Learning**: Scikit-learn (introduced in Phase 6)
* **Web Interface**: Streamlit (introduced in Phase 8)

## Project Phases
1. **Phase 1**: Basic Task Management (In-Memory CLI)
2. **Phase 2**: SQLite Database Integration
3. **Phase 3**: Smart Priority Scoring System
4. **Phase 4**: Reminder and Deadline System
5. **Phase 5**: Productivity Analytics
6. **Phase 6**: Machine Learning Task Completion Prediction
7. **Phase 7**: Explainable AI Recommendations
8. **Phase 8**: Streamlit Web Dashboard
